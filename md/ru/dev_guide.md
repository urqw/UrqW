### Справочник функций

| Функция | Описание |
| --- | --- |
| [Abs](#abs) | Вычисляет абсолютное значение числа. |
| [ArrayAdd](#arrayadd) | Добавляет элемент или элементы в массив. |
| [ArrayCopy](#arraycopy) | Создаёт полностью независимую копию массива. |
| [ArrayCreate](#arraycreate) | Создаёт массив указанной длины или на основе JSON. |
| [ArrayDel](#arraydel) | Удаляет элемент или элементы из массива. |
| [ArrayGet](#arrayget) | Возвращает элемент из массива. |
| [ArrayLen](#arraylen) | Возвращает количество элементов в массиве. |
| [ArraySet](#arrayset) | Устанавливает значение элемента в массиве. |
| [ArrayShuffle](#arrayshuffle) | Перемешивает массив с помощью алгоритма Фишера-Йейтса. |
| [Boolean](#boolean) | Возвращает логическое представление значения. |
| [Ceil](#ceil) | Возвращает число, округлённое до ближайшего целого числа в большую сторону. |
| [Date](#date) | Возвращает метку времени текущего или указанного времени. |
| [DateObject](#dateobject) | Возвращает объект, содержащий информацию о дате. |
| [Exp](#exp) | Вычисляет e в степени числа. |
| [FileContent](#filecontent) | Возвращает текстовое содержимое файла из игрового пакета. |
| [FileExists](#fileexists) | Проверяет, существует ли файл в игровом пакете. |
| [FileURL](#fileurl) | Возвращает относительный URL-адрес файла из игрового пакета. |
| [Floor](#floor) | Возвращает число, округлённое до ближайшего целого числа в меньшую сторону. |
| [Int](#int) | Возвращает целую часть числа, удаляя все цифры дробной части. |
| [IsArray](#isarray) | Проверяет, имеет ли значение ссылочный тип array. |
| [IsBoolean](#isboolean) | Проверяет, имеет ли значение примитивный тип boolean. |
| [IsFinite](#isfinite) | Проверяет, является ли значение конечным числом. |
| [IsInteger](#isinteger) | Проверяет, является ли значение целым числом. |
| [IsNaN](#isnan) | Проверяет, является ли значение NaN. |
| [IsNumber](#isnumber) | Проверяет, имеет ли значение примитивный тип number. |
| [IsObject](#isobject) | Проверяет, имеет ли значение ссылочный тип object. |
| [IsString](#isstring) | Проверяет, имеет ли значение примитивный тип string. |
| [JavaScript](#javascript) | Выполняет код JavaScript. |
| [Log](#log) | Вычисляет натуральный логарифм числа. |
| [Log10](#log10) | Вычисляет десятичный логарифм числа. |
| [Log2](#log2) | Вычисляет двоичный логарифм числа. |
| [Max](#max) | Возвращает наибольшее из переданных чисел. |
| [Min](#min) | Возвращает наименьшее из переданных чисел. |
| [Number](#number) | Возвращает числовое представление значения. |
| [ObjectCopy](#objectcopy) | Создаёт полностью независимую копию объекта. |
| [ObjectCreate](#objectcreate) | Создаёт объект: либо пустой, либо на основе JSON. |
| [ObjectDel](#objectdel) | Удаляет свойство (пару ключ-значение) из объекта. |
| [ObjectEntries](#objectentries) | Возвращает массив свойств объекта (пар ключ-значение). |
| [ObjectGet](#objectget) | Возвращает значение свойства (ключа) из объекта. |
| [ObjectKeys](#objectkeys) | Возвращает массив имён свойств объекта (ключей). |
| [ObjectSet](#objectset) | Устанавливает значение свойства (ключа) в объекте. |
| [ObjectValues](#objectvalues) | Возвращает массив значений свойств объекта. |
| [Pow](#pow) | Вычисляет число в степени. |
| [Round](#round) | Возвращает число, округлённое до указанного количества знаков после десятичного разделителя. |
| [Sqrt](#sqrt) | Вычисляет квадратный корень из числа. |
| [String](#string) | Возвращает строковое представление значения. |
| [StringLeft](#stringleft) | Возвращает символы в указанном количестве из левой стороны строки. |
| [StringLen](#stringlen) | Возвращает количество символов в строке. |
| [StringLocaleLower](#stringlocalelower) | Преобразует строку в нижний регистр, используя правила, специфичные для локали. |
| [StringLocaleUpper](#stringlocaleupper) | Преобразует строку в верхний регистр, используя правила, специфичные для локали. |
| [StringLower](#stringlower) | Преобразует строку в нижний регистр. |
| [StringMid](#stringmid) | Извлекает из строки определённое количество символов. |
| [StringRight](#stringright) | Возвращает символы в указанном количестве из правой стороны строки. |
| [StringSplit](#stringsplit) | Разделяет строку на подстроки в зависимости от заданного разделителя. |
| [StringTrim](#stringtrim) | Обрезает пробелы или определённое количество символов из начала и конца строки. |
| [StringTrimLeft](#stringtrimleft) | Обрезает либо пробелы, либо определённое количество символов с левой стороны строки. |
| [StringTrimRight](#stringtrimright) | Обрезает либо пробелы, либо определённое количество символов с правой стороны строки. |
| [StringUpper](#stringupper) | Преобразует строку в верхний регистр. |
| [TypeOf](#typeof) | Возвращает тип значения. |
| [UIHide](#uihide) | Скрывает и отображает элементы управления пользовательского интерфейса плеера. |
| [VarExists](#varexists) | Проверяет, существует ли переменная (определена ли она). |
