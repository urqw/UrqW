### Function Reference

| Function | Description |
| --- | --- |
| [Abs](#abs) | Calculates the absolute value of a number. |
| [ArrayAdd](#arrayadd) | Adds the element or elements to the array. |
| [ArrayCopy](#arraycopy) | Creates a completely independent copy of the array. |
| [ArrayCreate](#arraycreate) | Creates an array of the specified length or based on JSON. |
| [ArrayDel](#arraydel) | Deletes the element or elements from the array. |
| [ArrayGet](#arrayget) | Returns the element from the array. |
| [ArrayLen](#arraylen) | Returns the number of elements in the array. |
| [ArraySet](#arrayset) | Sets the value of the element in the array. |
| [ArrayShuffle](#arrayshuffle) | Shuffles an array using the Fisher-Yates algorithm. |
| [Boolean](#boolean) | Returns the boolean representation of a value. |
| [Ceil](#ceil) | Returns a number rounded up to the next integer. |
| [Date](#date) | Returns a timestamp of the current or specified time. |
| [DateObject](#dateobject) | Returns an object with date information. |
| [Exp](#exp) | Calculates e to the power of a number. |
| [FileContent](#filecontent) | Returns the text content of a file from a game package. |
| [FileExists](#fileexists) | Checks if a file exists in a game package. |
| [FileURL](#fileurl) | Returns the relative URL of a file from a game package. |
| [Floor](#floor) | Returns a number rounded down to the closest integer. |
| [Int](#int) | Returns the integer part of a number by removing any fractional digits. |
| [IsArray](#isarray) | Checks whether a value has the reference type array. |
| [IsBoolean](#isboolean) | Checks whether a value has the primitive type boolean. |
| [IsFinite](#isfinite) | Checks whether the value is a finite number. |
| [IsInteger](#isinteger) | Checks whether a value is an integer. |
| [IsNaN](#isnan) | Checks whether a value is NaN. |
| [IsNumber](#isnumber) | Checks whether a value has the primitive type number. |
| [IsObject](#isobject) | Checks whether a value has the reference type object. |
| [IsString](#isstring) | Checks whether a value has the primitive type string. |
| [JavaScript](#javascript) | Executes JavaScript code. |
| [Log](#log) | Calculates the natural logarithm of a number. |
| [Log10](#log10) | Calculates the common (decimal) logarithm of a number. |
| [Log2](#log2) | Calculates the binary logarithm of a number. |
| [Max](#max) | Returns the largest of the passed numbers. |
| [Min](#min) | Returns the smallest of the passed numbers. |
| [Number](#number) | Returns the number representation of a value. |
| [ObjectCopy](#objectcopy) | Creates a completely independent copy of the object. |
| [ObjectCreate](#objectcreate) | Creates an object: either empty or based on JSON. |
| [ObjectDel](#objectdel) | Deletes a property (key-value pair) from the object. |
| [ObjectEntries](#objectentries) | Returns an array of object properties (key-value pairs). |
| [ObjectGet](#objectget) | Returns a value of the property (key) from the object. |
| [ObjectKeys](#objectkeys) | Returns an array of object property names (keys). |
| [ObjectSet](#objectset) | Sets the value of the property (key) in the object. |
| [ObjectValues](#objectvalues) | Returns an array of object property values. |
| [Pow](#pow) | Calculates a number to a power. |
| [Round](#round) | Returns a number rounded to the specified number of decimal places. |
| [Sqrt](#sqrt) | Calculates the square-root of a number. |
| [String](#string) | Returns the string representation of a value. |
| [StringLeft](#stringleft) | Returns a number of characters from the left-hand side of the string. |
| [StringLen](#stringlen) | Returns a number of characters in the string. |
| [StringLocaleLower](#stringlocalelower) | Converts the string to lowercase using locale-specific rules. |
| [StringLocaleUpper](#stringlocaleupper) | Converts the string to uppercase using locale-specific rules. |
| [StringLower](#stringlower) | Converts the string to lowercase. |
| [StringMid](#stringmid) | Extracts a number of characters from the string. |
| [StringRight](#stringright) | Returns a number of characters from the right-hand side of the string. |
| [StringSplit](#stringsplit) | Splits up the string into substrings depending on the given delimiter. |
| [StringTrim](#stringtrim) | Trims whitespace characters or a number of characters from the beginning and end of the string. |
| [StringTrimLeft](#stringtrimleft) | Trims either whitespace characters or a number of characters from the left hand side of the string. |
| [StringTrimRight](#stringtrimright) | Trims either whitespace characters or a number of characters from the right hand side of the string. |
| [StringUpper](#stringupper) | Converts the string to uppercase. |
| [TypeOf](#typeof) | Returns the type of a value. |
| [UIHide](#uihide) | Hides and shows the player's UI controls. |
| [VarExists](#varexists) | Checks if a variable exists (is defined). |
